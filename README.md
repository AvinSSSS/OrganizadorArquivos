# Organizador de Arquivos / Batch File Organizer
Delphi VCL para renomeação em lote com prévia obrigatória, prefixo, sufixo, substituição, numeração, detecção de conflitos, log e desfazer da última operação.

Abra `FileOrganizer.dpr` no Delphi 13. Teste primeiro em uma pasta descartável.
